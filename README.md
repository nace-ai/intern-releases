# Intern releases

Downloads and the update feed for **Intern**, Nace's desktop app for
[nace-harness](https://github.com/nace-ai/nace-harness). macOS on Apple Silicon.

Download `Intern-<version>-arm64.dmg` from the [latest release](../../releases/latest) and drag
**Intern** into Applications. Installed apps update themselves from this repository.

This repository holds releases only. The source lives in a private repository.
